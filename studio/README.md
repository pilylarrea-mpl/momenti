# Studio

Working files behind the site. Nothing in here is published.

- `source/momenti.html`: the page source. Edit this, then run `python3 studio/scripts/build.py index.html` from the repo root to rebuild `index.html`.
- `renders/`: the original bag renders (1 Tokyo, 2 Havana, 3 Rome, 4 Havana blue, 5 logo, 6 Paris, 7 Miami, 8 Miami pink, 9 Monaco, 10 New York City).
- `clips/`: the Runway video shots at full quality.
- `social/`: finished videos for TikTok and Reels.
- `scripts/`: the scripts used to cut out the bags and make the videos.
